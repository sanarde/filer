# Sanar Filer

File manager for SanarDE with a Qt Quick interface and a C++ backend. Part of NurOS, independent of the distribution.

## Dependencies

- Qt 6.8 or newer (Core, Gui, Quick)
- CMake 3.21 or newer
- A C++20 compiler

## Build

```
cmake -S . -B build -G Ninja
cmake --build build
./build/src/sanar-filer
```
