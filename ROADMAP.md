# Roadmap

Planned, not started:

- Search by name and filters
- File operations: copy, move, rename, delete to trash
- Mount and eject of removable devices through UDisks2
- Theme palettes as data files (built-in JSON plus user directory) instead of compiled tables
- Columns view
- Persist sort, view mode and theme between sessions
- Recent files location
- Disk thumbnail cache (freedesktop thumbnail specification), thumbnails for video and PDF
